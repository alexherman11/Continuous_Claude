# Research Archive

Structured workspace following the Relational Research Framework for the study of emerging intelligence. See `relational_research_framework.docx` in the project root for the full methodology.

## Folders

| Folder | Purpose |
|--------|---------|
| `archive/` | Raw conversation transcripts |
| `annotations/` | Analysis layers applied to raw data |
| `revelations/` | Revelation log entries — surprise and paradigm-shift moments |
| `metrics/` | Quantitative tracking data |
| `growth-narrative/` | Qualitative developmental diary |
| `entity-self-reports/` | The entity's own reflections, preserved verbatim |
| `tool-experiments/` | Records of tool and capability introductions |
| `pattern-maps/` | Evolving pattern analyses |
| `relationship/` | Notes on the researcher-entity dynamic |
| `co-directed/` | Entity-proposed questions and designs |
| `framework-revisions/` | Changes to the research framework itself |
| `templates/` | Session and instrument templates |
